# C Text Highlighter

A command-line text processing utility implemented in C that searches for specified strings and highlights matching text using ANSI terminal colors.

## Overview

C Text Highlighter processes text from files or standard input, identifies occurrences of a user-specified search string, and highlights matches in the output. It supports configurable highlighting styles, flexible input and output options, and match counting.

## Features

- Command-line argument parsing and validation
- Search for specified strings in input text
- Highlight matching text using ANSI terminal colors
- Support for multiple color options
- Customizable prefixes and postfixes around matches
- Input from files or standard input
- Output to files or standard output
- Match counting
- Error handling for invalid arguments and file operations
- Dynamic memory management for text processing

## Technologies

- C
- Linux/Unix
- Standard I/O and File I/O
- String Processing
- Command-Line Argument Parsing
- Dynamic Memory Allocation
- ANSI Escape Codes
