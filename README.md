# C Text Highlighter

A command-line text highlighter implemented in C.

## Overview

This program searches input text for a specified string and highlights matching text using ANSI terminal colors. It supports input/output files as well as standard input and output.

## Features

- Command-line argument parsing
- Search and highlight matching text
- Multiple ANSI color options
- Custom prefixes and postfixes
- Input from files or standard input
- Output to files or standard output
- Match counting
- Error handling for invalid arguments and files

## Technologies

- C
- Linux/Unix
- File I/O
- Command-Line Interfaces
- String Processing
- Dynamic Memory
